1. Buka Dokumen Baru → Blank Document.
  2. Atur font dan ukuran:
    1. Tab Home → pada Group Font.
    2. Pilih font: Times New Roman, size: 12 pt.
  3. Buat Kop Surat:
    1. Ketik Judul "PT MAJU BERSAMA INDONESIA".
    2. Blok teks → Ctrl + B → ubah ukuran Font menjadi 14 pt.
    3. Klik Tengah (Ctrl + E) untuk Rata Tengah.
    4. Tekan Enter, kemudian ketik Alamat Perusahaan.
    5. Ubah ukuran Font menjadi 10 pt dan Rata Tengah.
    6. Klik Insert → Shapes → pilih Line.
    7. Drag garis dari kiri ke kanan di bawah Alamat Perusahaan.
    8. Atur ketebalan garis melalui Shape Format → Shape Outline → Weight.
  4. Buat Isi Surat:
    1. Ketik: "Jakarta, 15 Januari 2025" (Tanggal Surat).
    2. Tekan Enter → ketik: "Lampiran: 1 (satu) lembar".
    3. Tekan Enter → ketik: "Hal: Undangan Rapat Evaluasi Kinerja".
    4. Tekan Enter → ketik: "Kepada Yth. Bapak/Ibu Karyawan".
    5. Tekan Enter → ketik: "Dengan hormat,".
    6. Tekan Enter → ketik paragraf Isi Undangan, misal:
      "Dengan ini kami mengundang Bapak/Ibu untuk menghadiri Rapat Evaluasi Kinerja yang akan dilaksanakan di Ruang Meeting Lantai 3 pada Senin, 20 Januari 2025 pukul 09.00 WIB."
    7. Blok Isi Surat dari Paragraph 1 - 4 → klik Justify (Ctrl+J).
    8. Tempat dan Agenda: blok → Italic (Ctrl+I).
    9. Tanggal: blok → Underline (Ctrl+U).

  2. Buat WordArt Judul:

    3. Blok Teks "PRODUK TERBARU" → Tab Insert → Group Text → klik WordArt.
    4. Pilih Gaya WordArt (Misalnya Fill: Blue, Accent color 1; Shadow).
    5. Tekan Enter 2x setelah WordArt untuk jarak.
  3. Buat Tabel Daftar Produk:
    1. Tab Insert → Table → Insert Table → isi 5 Baris × 4 kolom (1 Header + 4 Data).
    2. Isi Header: No, Nama Produk, Harga, Stok.
    3. Isi 4 Baris data sesuai tabel contoh di atas.
    4. Blok Header → Bold (Ctrl+B) → Tengah (Ctrl+E).
    5. Blok Header → klik kanan → Borders and Shading → Tab Shading → pilih Warna Gelap misal: Dark Blue → OK.
    6. Dengan Header masih terblok → ubah Font Color menjadi White.

Donec id condimentum dui, sed ullamcorper libero. Mauris id turpis vestibulum, vestibulum erat pulvinar, dapibus mi. Phasellus tincidunt nisi tortor, sed mattis mi imperdiet quis.     5. Untuk mengatur Jarak dari teks Huruf Awal dengan huruf berikutnya: Drop Cap Options → Distance from text: misal: 0,1 cm.
  5. Sisipkan Gambar Produk:

  1. Buka dokumen baru → ubah Orientation ke Landscape (Tab Layout → Orientation → Landscape) agar infografis lebih luas.
  2. Buat WordArt Judul utama:
    1. Tab Insert → Group Text → WordArt.
    2. Pilih gaya menarik → ketik: "STRUKTUR ORGANISASI".
      • Rata Tengah (Ctrl+E) → posisikan di tengah atas halaman.
    3. Tekan Enter 2x
  3. Buat SmartArt Hierarchy 3 level:
    1. Tab Insert → SmartArt → pilih Hierarchy → Organization Chart.
      Klik OK → SmartArt akan muncul di dokumen.
      Pada Layout Options → Square
      Ubah Kotak menjadi seperti ini:
      Dengan Cara:
    2. Di panel kiri SmartArt, isi nama jabatan sesuai tabel contoh di atas.
    3. Untuk menambah level: klik shape → Tab SmartArt Design → Add Shape → Add Shape Below.
    4. Untuk mengisi nama: klik shape → ketik langsung di shape atau di panel teks.
    5. Ubah warna: SmartArt Design → Change Colors → pilih skema warna.
  4. Tambahkan Shapes dekoratif:
    1. Tab Insert → Shapes → pilih Rounded Rectangle atau Oval.
    2. Gambar di area kosong → Shape Fill pilih warna gradasi.
    3. Insert → Shapes → Arrow untuk membuat garis penghubung.
    4. Klik kanan shape → Edit Text untuk menambahkan teks di dalam shape.
  5. Sisipkan gambar:
    1. Tab Insert → Pictures → pilih gambar/foto tim.
    2. Klik gambar → Tab Picture Format → Wrap Text → pilih Tight atau Through agar menyatu dengan elemen lain.
  6. Atur layering (Bring to Front / Send to Back):
    1. Klik kanan objek → Bring to Front (tampil di depan) atau Send to Back (tampil di belakang).
    2. Gunakan untuk menumpuk shapes, gambar, dan teks secara artistik.
    3. Tips: Jika objek tertumpuk dan sulit diklik, gunakan Tab untuk berpindah antar objek.
  7. Grup objek:
    1. Klik objek pertama → tahan Shift → klik objek lainnya satu per satu.
    2. Klik kanan → Group → Group.
    3. Sekarang semua objek menjadi satu kesatuan yang mudah dipindahkan.
    4. Untuk meng-ungroup: klik kanan group → Group → Ungroup.
  8. Simpan: File → Save As → Infografis_Satu_Halaman.docx.
