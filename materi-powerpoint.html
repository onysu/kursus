Pertemuan 1 Pengenalan PowerPoint, SmartArt & Shapes
Langkah Praktik:
  1. Dasar: Buat 3 slide presentasi diri: (1) Cover nama & foto, (2) Pendidikan & pengalaman, (3) Hobi & minat. Gunakan tema bawaan PowerPoint.

    1. Buka PowerPoint → pilih Blank Presentation.
    2. Pilih tema: Tab Design → pilih salah satu tema (misal: Ion, Retrospect, atau Frame).
    3. Slide 1 — Cover:
      • Hapus placeholder "Click to add title".
      • Tab Insert → Text Box → ketik: "Nama Lengkap" (font besar 44 pt).
      • Insert → Pictures → pilih foto diri (atau gambar placeholder).
      • Atur foto: pilih → Picture Format → Crop → Crop to Shape → pilih Oval.
      • Tambahkan teks tambahan: jurusan/kelas, font 20 pt.
    4. Slide 2 — Pendidikan & Pengalaman:
      • Klik kanan di slide panel → New Slide.
      • Judul: "Pendidikan & Pengalaman".
      • Isi dengan bullet list: riwayat sekolah, organisasi, kursus.
      • Gunakan Bullets & Numbering di tab Home.
    5. Slide 3 — Hobi & Minat:
      • New Slide → judul: "Hobi & Minat".
      • Gunakan Icons (Insert → Icons) untuk mempercantik, misal: ikon musik, olahraga, buku.
      • Beri deskripsi singkat.
    6. Simpan file: File → Save As → beri nama Presentasi_Diri.pptx.
    Contoh Latihan
  2. Menengah: Buat SmartArt Hierarchy struktur organisasi (Direktur → Manager → Staff). Buat diagram proses bisnis (Prospek → Penawaran → Negosiasi → Deal) menggunakan shapes + panah. Gunakan SmartArt Cycle.

    Bagian 1 — Struktur Organisasi (SmartArt Hierarchy)
    1. Buat slide baru → judul: "Struktur Organisasi".
    2. Tab Insert → SmartArt → pilih Hierarchy → pilih Organization Chart.
    3. Klik kotak paling atas → ketik: Direktur.
    4. Klik kotak level 2 → ketik: Manager. Ulangi untuk manager kedua.
    5. Klik kotak level 3 → ketik: Staff untuk masing-masing manager.
    6. Menambah kotak: klik kanan pada kotak → Add Shape → pilih Add Shape Below atau Add Assistant.
    7. Ubah warna: Tab SmartArt Design → Change Colors → pilih skema warna.
    Bagian 2 — Diagram Proses Bisnis (Shapes + Panah)
    1. Buat slide baru → judul: "Proses Bisnis".
    2. Tab Insert → Shapes → pilih Rounded Rectangle.
    3. Gambar 4 kotak secara horizontal beri jarak.
    4. Klik kanan masing-masing → Edit Text → ketik: Prospek, Penawaran, Negosiasi, Deal.
    5. Insert → Shapes → pilih Arrow (Right) → gambar panah dari kotak 1 ke 2, 2 ke 3, 3 ke 4.
    6. Blok semua shapes + panah → Tab Shape Format → Align → Align Middle, lalu Distribute Horizontally agar jarak antar kotak sama rata.
    7. Ubah warna shapes: Shape Fill → pilih warna biru gradasi.
    Bagian 3 — SmartArt Cycle
    1. Buat slide baru → judul: "Siklus Penjualan".
    2. Insert → SmartArt → pilih Cycle → Basic Cycle atau Continuous Cycle.
    3. Ketik teks di masing-masing lingkaran: Prospek, Penawaran, Negosiasi, Deal.
    4. Ubah warna dan gaya dari tab SmartArt Design.
    Contoh Latihan
  3. Lanjutan: Buat profil perusahaan 5 slide: (1) Cover dengan logo, (2) Visi-Misi, (3) Struktur organisasi (SmartArt), (4) Produk & layanan, (5) Penutup. Gunakan tema kustom dengan warna korporat.

    1. Tentukan skema warna korporat (misal: biru #005A9E + abu #F2F2F2).
    2. Slide 1 — Cover:
      • Judul: "Nama Perusahaan".
      • Subtitle: "Profil Perusahaan 2025".
      • Insert → Pictures → logo perusahaan (atau buat dengan Shapes + Text Box).
      • Atur tata letak: logo di kiri, teks di kanan.
    3. Slide 2 — Visi & Misi:
      • Judul: "Visi & Misi".
      • Visi: 1 kalimat tebal di tengah.
      • Misi: 3-5 bullet point.
      • Gunakan ikon (Insert → Icons) untuk mempercantik.
    4. Slide 3 — Struktur Organisasi (SmartArt):
      • Insert → SmartArt → Hierarchy → Organization Chart.
      • Isi: Direktur Utama → Manager → Staff.
      • Ubah warna sesuai tema korporat.
    5. Slide 4 — Produk & Layanan:
      • Gunakan layout 2 kolom atau grid shapes.
      • Setiap produk: ikon + nama + deskripsi singkat.
    6. Slide 5 — Penutup:
      • "Terima Kasih" besar di tengah.
      • Kontak: Email, Telepon, Website.
      • Sosial media: ikon Instagram, LinkedIn, dll.
    7. Menerapkan tema kustom: Tab Design → Variants → sesuaikan warna (Colors → Customize Colors) dan font.

Pertemuan 2 Gambar, Video, Hyperlink & Animasi
Contoh Praktik:
  1. Dasar: Sisipkan 2 gambar ke dalam slide. Gunakan Remove Background pada salah satu gambar. Crop gambar menjadi bentuk circle. Atur posisi dan ukuran.

    1. Buka PowerPoint → Blank Presentation.
    2. Sisipkan gambar pertama:
      • Tab Insert → Pictures → This Device → pilih file gambar.
      • Atur posisi di kiri slide, ukuran sesuai.
    3. Sisipkan gambar kedua + Remove Background:
      • Insert → Pictures → pilih gambar kedua.
      • Klik gambar → Tab Picture Format → Remove Background.
      • PowerPoint akan mendeteksi latar belakang secara otomatis (warna ungu = area yang akan dihapus).
      • Jika ada area yang salah deteksi: gunakan Mark Areas to Keep atau Mark Areas to Remove.
      • Tips: Zoom in (Ctrl + scroll) untuk marking yang lebih presisi.
      • Klik Keep Changes → latar belakang gambar hilang.
    4. Crop gambar menjadi bentuk circle:
      • Klik gambar → Tab Picture Format → Crop → Crop to Shape.
      • Pilih Oval (dalam kategori Basic Shapes).
      • Sesuaikan posisi crop dengan drag handle.
      • Tekan Enter atau klik di luar gambar untuk selesai.
    5. Atur posisi dan ukuran:
      • Klik gambar → drag sudut untuk mengubah ukuran (tahan Shift agar proporsional).
      • Drag gambar untuk memindahkan posisi.
      • Gunakan Picture Format → Position untuk pengaturan presisi.
    6. Tambahkan efek gambar (opsional):
      • Tab Picture Format → Picture Border → beri border putih.
      • Picture Effects → Shadow → pilih efek bayangan.
    Contoh Latihan
  2. Menengah: Buat presentasi interaktif dengan: slide menu utama + hyperlink ke slide masing-masing bab, Action Button "Kembali" di setiap slide. Tambahkan video pendek dari YouTube.

    1. Buat struktur slide:
      • Slide 1: Menu Utama
      • Slide 2: Bab 1 — Pendahuluan
      • Slide 3: Bab 2 — Materi
      • Slide 4: Bab 3 — Kesimpulan
      • Slide 5: Video
    2. Slide 1 — Menu Utama:
      • Judul: "Menu Presentasi".
      • Buat 3 teks: "Bab 1", "Bab 2", "Bab 3".
      • Blok teks "Bab 1" → Klik kanan → Hyperlink (atau Ctrl+K).
      • Pilih Place in This Document → pilih Slide 2 (Bab 1) → OK.
      • Ulangi untuk "Bab 2" → Slide 3, "Bab 3" → Slide 4.
    3. Tambahkan Action Button "Kembali" di setiap slide:
      • Buka Slide 2 (Bab 1).
      • Tab Insert → Shapes → Action Buttons → pilih Action Button: Home (ikon rumah).
      • Gambar di pojok kanan bawah.
      • Di dialog yang muncul: pilih Hyperlink to → First Slide atau Slide… → pilih Slide 1.
      • Klik OK.
      • Copy-paste action button ke Slide 3, 4, dan 5.
    4. Tambahkan video dari YouTube:
      • Buka Slide 5 → judul: "Video".
      • Tab Insert → Video → Online Video.
      • Paste URL YouTube (atau cari "Embed Code" dari YouTube).
      • Klik Insert → video akan muncul di slide.
      • Alternatif: Jika Online Video gagal, gunakan Insert → Video → This Device dengan file video .mp4 yang sudah di-download.
      • Atur ukuran dan posisi video.
      • Set video play otomatis: Tab Video Format → Play Video → Automatically.
    5. Uji coba: Tekan F5 (Slide Show) → klik "Bab 1" → navigasi → klik Action Button kembali → coba video.
    Contoh Latihan
  3. Lanjutan: Buat animasi proses bisnis: teks "Prospek" muncul (On Click) → panah → "Penawaran" muncul → panah → "Negosiasi" muncul → panah → "Deal" muncul. Gunakan Entrance (Fade) + Emphasis (Grow) + Motion Path. Atur timing After Previous untuk efek otomatis.

    1. Buat slide baru → judul: "Proses Bisnis — Animasi".
    2. Buat objek di slide:
      • Buat 4 kotak (Insert → Shapes → Rounded Rectangle) secara horizontal berjauhan.
      • Isi teks: Prospek, Penawaran, Negosiasi, Deal.
      • Format warna: biru muda, border biru tua.
      • Buat 3 panah (Insert → Shapes → Arrow: Right) di antara kotak.
    3. Tambahkan animasi Entrance (Fade):
      • Klik kotak "Prospek" → Tab Animations → pilih Fade.
      • Klik panah setelah "Prospek" → pilih Fade.
      • Klik kotak "Penawaran" → pilih Fade.
      • Ulangi untuk semua objek secara berurutan.
    4. Atur timing animasi:
      • Buka Animation Pane (Tab Animations → Animation Pane).
      • Klik panah bawah pada masing-masing animasi di panel → atur:
      • "Prospek" → Start: On Click (muncul saat klik).
      • Panah 1 → Start: After Previous (otomatis setelah Prospek).
      • "Penawaran" → Start: With Previous (bersamaan dengan panah 1).
      • Panah 2 → Start: After Previous.
      • "Negosiasi" → Start: With Previous.
      • Panah 3 → Start: After Previous.
      • "Deal" → Start: With Previous.
    5. Tambahkan Emphasis (Grow) pada "Deal":
      • Klik kotak "Deal" → Tab Animations → Add Animation.
      • Pilih Grow/Shrink (dalam Emphasis).
      • Atur Start: With Previous, Duration: 1s.
    6. Tambahkan Motion Path pada "Prospek" (opsional):
      • Klik "Prospek" → Add Animation → Motion Paths → Lines.
      • Drag garis hijau (start) ke posisi awal, garis merah (end) ke posisi akhir.
      • Atur Start: With Previous, Duration: 2s.
    7. Uji coba: Tekan F5 → klik sekali → animasi berjalan otomatis berurutan.

Pertemuan 3 Transisi, Slide Master & Template Kustom
Contoh Praktik:
  1. Dasar: Buat 4 slide berurutan. Terapkan transisi berbeda: Fade, Push, Wipe, Morph. Atur durasi 2 detik dan auto-advance After 3 detik.

    1. Buka PowerPoint → Blank Presentation.
    2. Buat 4 slide: Klik kanan di slide panel → New Slide (ulangi 3 kali).
    3. Isi tiap slide dengan judul berbeda: "Slide 1 — Fade", "Slide 2 — Push", "Slide 3 — Wipe", "Slide 4 — Morph".
    4. Terapkan transisi:
      • Klik Slide 1 → Tab Transitions → pilih Fade.
      • Klik Slide 2 → pilih Push.
      • Klik Slide 3 → pilih Wipe.
      • Klik Slide 4 → pilih Morph.
    5. Atur durasi transisi:
      • Di tab Transitions, pada grup Timing:
      • Duration: ketik 02.00 (2 detik).
      • Ulangi untuk masing-masing slide.
    6. Atur auto-advance:
      • Pada grup Timing, centang After → ketik 00:03.00 (3 detik).
      • Penting: Biarkan On Mouse Click tetap tercentang agar slide tetap bisa diklik manual sewaktu-waktu.
      • Ulangi untuk semua slide.
      • Jalankan slide show (F5) → slide akan berganti otomatis setiap 3 detik.
    Contoh Latihan
  2. Menengah: Buat Morph transition antar 2 slide: slide 1 berisi teks "IDE" besar di kiri, slide 2 teks "IDE" mengecil di kanan dengan deskripsi. Duplikat slide dan atur objek untuk efek Morph sinematik.

    1. Buat Slide 1:
      • Hapus semua placeholder default.
      • Insert → Text Box → ketik: "IDE".
      • Font: Arial Black, size 96 pt, warna biru tua.
      • Posisikan di pojok kiri slide.
    2. Duplikat Slide 1 menjadi Slide 2:
      • Klik kanan Slide 1 di panel → Duplicate Slide.
    3. Edit Slide 2:
      • Pindahkan teks "IDE" ke pojok kanan atas.
      • Ubah ukuran font menjadi 36 pt.
      • Tambahkan Text Box baru dengan deskripsi: "Sebuah gagasan yang mengubah dunia".
      • Font deskripsi: 20 pt, warna abu-abu.
      • Tambahkan gambar ilustrasi (Insert → Pictures) di tengah slide.
    4. Terapkan Morph transition pada Slide 2:
      • Klik Slide 2 → Tab Transitions → pilih Morph.
      • Durasi: set 02.00 (2 detik).
    5. Uji coba: Tekan F5 → klik ke Slide 2 → teks "IDE" akan bergerak mulus dari kiri ke kanan sambil mengecil, sementara deskripsi dan gambar muncul.
    Contoh Latihan
  3. Lanjutan: Buat template perusahaan kustom: (1) Logo di kanan atas semua slide (Slide Master), (2) Warna korporat (biru + abu) di theme colors, (3) Font Calibri konsisten, (4) Layout kustom "Judul + Gambar Kiri". Simpan sebagai .potx.

    1. Buka Slide Master:
      • Tab View → Slide Master.
      • Slide Master adalah slide paling atas di panel kiri.
    2. Tambahkan logo di semua slide:
      • Pilih slide paling atas (Slide Master).
      • Insert → Pictures → pilih logo perusahaan.
      • Posisikan di kanan atas slide master.
      • Atur ukuran logo (jangan terlalu besar).
      • Logo akan muncul di semua slide yang menggunakan layout di bawahnya.
    3. Kustomisasi warna korporat:
      • Tab Slide Master → Colors → Customize Colors.
      • Isi:
      • Accent 1: Biru (#005A9E)
      • Accent 2: Abu-abu (#F2F2F2)
      • Beri nama: "Warna Korporat" → Save.
    4. Atur font korporat:
      • Tab Slide Master → Fonts → Customize Fonts.
      • Heading: Calibri Light.
      • Body: Calibri.
      • Beri nama: "Font Korporat" → Save.
    5. Buat layout kustom "Judul + Gambar Kiri":
      • Di panel Slide Master, klik Insert Layout (atau kanan → Insert Layout).
      • Klik kanan layout baru → Rename Layout → ketik: "Judul + Gambar Kiri".
      • Insert → Placeholder → pilih Picture → tempatkan di kiri.
      • Insert Placeholder → Title → tempatkan di kanan atas.
      • Insert Placeholder → Text → tempatkan di kanan bawah.
    6. Keluar dari Slide Master: Klik Close Master View.
    7. Simpan sebagai template:
      • File → Save As.
      • Pilih file type: PowerPoint Template (*.potx).
      • Beri nama: "Template_Korporat.potx".
      • Template siap digunakan untuk presentasi selanjutnya.

Pertemuan 4 Final Presentasi & Teknik Presentasi
Contoh Praktik:
  1. Dasar: Buat 5 slide presentasi produk sederhana. Gunakan Presenter View untuk melihat notes. Latih Rehearsal Timing agar selesai tepat 3 menit.

    1. Buat 5 slide presentasi produk:
      • Slide 1: Cover — Nama Produk + Tagline.
      • Slide 2: Fitur Utama — 3 fitur dengan ikon.
      • Slide 3: Manfaat — bullet point manfaat produk.
      • Slide 4: Testimoni — quote pelanggan.
      • Slide 5: Call to Action — kontak + harga.
    2. Tambahkan Speaker Notes:
      • Klik Notes di bagian bawah slide (atau View → Notes Page).
      • Ketik skrip presentasi di notes tiap slide.
    3. Gunakan Presenter View:
      • Tekan Alt+F5 (atau Slide Show → Presenter View).
      • Layar presenter: menampilkan slide, notes preview, timer, dan slide berikutnya.
      • Pastikan proyektor/layar kedua terhubung untuk hasil optimal.
    4. Latih Rehearsal Timing:
      • Tab Slide Show → Rehearse Timings.
      • PowerPoint akan merekam waktu tiap slide.
      • Presentasikan seperti biasa → klik next untuk berpindah slide.
      • Setelah selesai, PowerPoint menanyakan: "Keep the slide timings?" → pilih Yes.
      • Sesuaikan agar total waktu mendekati 3 menit.
      • Tekan F5 → slide show akan berjalan otomatis sesuai timing yang direkam.
    Contoh Latihan
  2. Menengah: Buat business pitch 7 slide: (1) Cover, (2) Masalah & Solusi, (3) Produk (gambar), (4) Market Size (chart), (5) Business Model, (6) Tim (SmartArt), (7) Call to Action. Gunakan Morph transisi dan animasi Entrance.

    1. Buat 7 slide dengan struktur berikut:
    Slide Judul Konten
    1 Cover Nama startup + tagline + nama presenter
    2 Masalah & Solusi Problem statement + solusi yang ditawarkan
    3 Produk Gambar produk, fitur utama
    4 Market Size Grafik/chart potensi pasar (Insert → Chart)
    5 Business Model Bagaimana menghasilkan uang, harga, margin
    6 Tim SmartArt Hierarchy atau Picture Layout
    7 Call to Action Yang diinginkan (investasi/kerjasama) + kontak
    1. Terapkan tema yang profesional dan konsisten (Design → pilih tema, misal: Ion atau Banded).
    2. Gunakan Morph transisi antar slide: Terapkan Morph pada Slide 2-7 (Transitions → Morph).
    3. Tambahkan animasi Entrance (Fade):
      • Pilih judul slide → Animations → Fade (Start: After Previous).
      • Pilih konten slide → Animations → Fade (Start: After Previous).
      • Ulangi untuk semua slide agar elemen muncul otomatis.
    4. Slide 4 — Market Size:
      • Tab Insert → Chart → pilih Bar atau Pie.
      • PowerPoint akan membuka jendela Excel kecil — ketik data pasar Anda, lalu tutup Excel.
      • Format chart agar sesuai tema warna.
    5. Slide 6 — Tim:
      • Insert → SmartArt → Picture → Picture Organization Chart atau Circle Picture.
      • Klik ikon kamera di SmartArt → pilih foto tim.
      • Ketik nama dan jabatan.

  3. Lanjutan (Final): Buat presentasi final 7 slide dengan ketentuan: template kustom (Slide Master), Morph transisi antar slide, animasi Entrance di setiap elemen, hyperlink navigasi ke slide tertentu, video/gambar, Record Slide Show. Presentasikan langsung dengan Presenter View.

    Ini adalah final project yang menggabungkan seluruh materi Pertemuan 1-4.

    1. Buat template kustom (Slide Master) — rujuk Pertemuan 3:
      • Buka Slide Master (View → Slide Master).
      • Tambahkan logo di slide master.
      • Kustomisasi warna dan font korporat.
      • Buat layout "Judul + Gambar Kiri" jika diperlukan.
      • Close Master View.
    2. Buat 7 slide dengan konten pilihan bebas (profil perusahaan, produk, project sekolah, dll):
      • Slide 1: Cover — judul + subtitle + logo.
      • Slide 2: Daftar Isi / Menu — dengan hyperlink ke slide masing-masing.
      • Slide 3: Isi 1 — teks + gambar.
      • Slide 4: Isi 2 — chart/grafik/data.
      • Slide 5: Isi 3 — video (Insert → Video).
      • Slide 6: Isi 4 — SmartArt / diagram.
      • Slide 7: Penutup — Call to Action + kontak.
    3. Hyperlink navigasi (rujuk Pertemuan 2):
      • Di Slide 2 (Daftar Isi), buat hyperlink masing-masing item ke slide tujuan.
      • Tambahkan Action Button "Kembali ke Menu" di setiap slide (kecuali Cover).
    4. Morph transisi: Terapkan Morph di semua slide (kecuali mungkin slide 1 → 2).
      Tips: duplikat slide sebelumnya, ubah posisi objek, lalu terapkan Morph untuk efek sinematik.
    5. Animasi Entrance:
      • Judul: Fade, Start: After Previous.
      • Konten: Fade, Start: After Previous (agar muncul otomatis).
      • Gambar: Float In atau Zoom, Start: With Previous.
    6. Record Slide Show:
      • Tab Slide Show → Record Slide Show.
      • Pilih Record from Beginning.
      • Bicara menjelaskan tiap slide + klik navigasi.
      • Setelah selesai, klik Close → rekaman tersimpan di slide.
      • Ikon speaker muncul di tiap slide yang direkam.
    7. Presentasikan dengan Presenter View:
      • Tekan Alt+F5 untuk Presenter View.
      • Gunakan notes untuk panduan bicara.
      • Gunakan pointer/pen (Ctrl+P) untuk menandai slide.
      • Tekan B untuk layar hitam, W untuk layar putih (saat diskusi).
    8. Export sebagai video (opsional):
      • File → Export → Create a Video.
      • Pilih kualitas: Full HD (1080p).
      • Atur timing tiap slide (default 5 detik).
      • Klik Create Video → simpan sebagai .mp4.
    Kriteria Penilaian Final Project:
    • Template kustom (Slide Master) — 20%
    • Konten & tata letak — 20%
    • Animasi & Transisi (Morph) — 20%
    • Hyperlink & Navigasi interaktif — 15%
    • Media (gambar/video) — 10%
    • Teknik presentasi (Presenter View + Record) — 15%
