Latihan PPT 2024 — Presentasi Diri 3 Slide: Buat presentasi diri sederhana dengan foto, ikon, dan teks menggunakan tema bawaan PowerPoint. Pelajari cara menyisipkan gambar, mengatur tata letak, dan mempercantik dengan ikon.
  1. Buka PowerPoint → pilih Blank Presentation.
  2. Pilih tema: Tab Design → pilih salah satu tema (misal: Office 2013 - 2022 Theme).
  3. Slide 1 — Cover:
    1. "Click to add title" ketik: "PRESENTASI DIRI" (font besar 44 pt).
    2. Tab Insert → Text Box
      • Nama : Andi Pratama (font besar 18 pt).
      • Kelas : Peserta Kursus Office (font besar 18 pt).
    3. Klik Insert → Pictures → This Device.
    4. Atur foto: Klik 2x pada Foto → Picture Format → Crop → Crop to Shape → pilih Oval.
  4. Slide 2 — Pendidikan & Pengalaman:
    • Klik tab Home.
    • Klik New Slide.
    • Pilih layout Two Content.

    Isi:

    1. Judul (atas): ketik "PENDIDIKAN & PENGALAMAN", font 36-40 pt.
    2. Kiri
      Pendidikan
      • SD Negeri 01 Surabaya
      • SMP Negeri 05 Surabaya
      • SMA Negeri 10 Surabaya
    3. Kanan
      Pengalaman
      • Ketua Kelas (2023)
      • Panitia Acara Sekolah
      • Magang Administrasi (2025)
    4. Font isi: 18-20 pt agar terbaca jelas.
  5. Slide 3 — Hobi & Minat:
    • Klik Home → New Slide.
    • Pilih layout Title Only
      Judul: "Hobi & Minat", font 36-40 pt.
    • Klik Insert → Icons.
      Pada kotak pencarian, cari:
      • Music
      • Sport
      • Book
      Pilih beberapa ikon dan Klik Insert.
    Atur posisi ikon berjajar secara horizontal dengan cara
    Pilih atau seleksi ketiga icon.
    Pada Tab Graphics Format → Klik Align → pilih Align Middle dan Distribute Horizontally.
    Untuk mengubah warna ikon: Pilih ikon → Tab Graphics Format → Graphics Fill → pilih warna.
    Gunakan Text Box di bawah masing-masing ikon.
    • Musik (font 20-22 pt tebal)
      Mendengarkan musik untuk hiburan dan relaksasi.
    • Olahraga (font 20-22 pt tebal)
      Bermain badminton untuk menjaga kesehatan.
    • Membaca (font 20-22 pt tebal)
      Membaca buku teknologi dan pengembangan diri.

    👉 Gunakan Align untuk menata posisi teks agar sejajar dengan ikon.

    Pilih semua Text Box (3 Text Box) → Tab Shape Format → Klik Align → pilih Align Middle dan Distribute Horizontally.
    Jangan lupa untuk teks Rata Tengah semua.
  6. Simpan file: File → Save → beri nama misalnya Presentasi_Diri.pptx.

Latihan PPT 2024 — Struktur Organisasi & Diagram Bisnis: Buat SmartArt Hierarchy struktur organisasi, Shapes + Arrows diagram proses bisnis, dan SmartArt Cycle siklus penjualan. Gunakan align, gradient, dan ubah warna tema.
Bagian 1 — Struktur Organisasi
  1. Buka PowerPoint → pilih Blank Presentation.
  2. Layout → Title Only → judul: STRUKTUR ORGANISASI.
  3. Tab Insert → SmartArt → pilih Hierarchy → pilih Organization Chart.
  4. Klik kotak paling atas → ketik: Direktur.
  5. Klik kotak level 2 → ketik: Manager.
  6. Klik kotak level 3 → ketik: Staff untuk masing-masing manager.
  7. Jika ingin menambah kotak: Klik kanan pada Kotak → Add Shape → pilih Add Assistant.
  1. Jika ingin ubah warna: Tab SmartArt Design → Change Colors → pilih skema warna.
  1. Jika ingin ubah Tema: Tab SmartArt Styles → pilih tema warna.
Bagian 2 — Diagram Proses Bisnis
  1. Buat Slide baru: klik panah kecil New Slide → Title Only → judul: PROSES BISNIS.
  2. Tab Insert → Shapes → pilih Rectangle: Rounded Corners.
  3. Gambar 4 kotak secara horizontal dengan jarak kurang lebih sama (gunakan align nanti di langkah 6).
  4. Klik kanan masing-masing kotak → Edit Text → ketik: PROSPEK, PENAWARAN, NEGOSIASI, DEAL.
  1. Insert → Shapes → pilih Arrow (Right) → gambar panah dari kotak 1 ke 2, 2 ke 3, 3 ke 4.
  1. Blok semua shapes + panah → Tab Shape Format → Align → Align Middle, lalu Distribute Horizontally agar jarak antar kotak sama rata.
  1. Ubah warna shapes: Shape Fill → Gradient pilih warna biru gradasi.
Bagian 3 — SmartArt Cycle
  1. Buat Slide baru: klik panah kecil New Slide → Title Only → judul: SIKLUS PENJUALAN.
  2. Insert → SmartArt → pilih Cycle → Basic Cycle.
  3. Ketik teks di masing-masing lingkaran: Prospek, Penawaran, Negosiasi, Deal.
  4. Jika ingin ubah warna dan gaya, klik SmartArt di halaman Slide kemudian dari Tab SmartArt Design.
Animasi (Opsional): Tambahkan animasi Fade atau Wipe pada tiap SmartArt/Shape agar presentasi lebih hidup. Atur Start → After Previous di Animation Pane agar animasi berjalan otomatis.

Latihan PPT 2024 — Profil Perusahaan 5 Slide: Buat profil perusahaan lengkap dengan tema kustom (warna & font korporat), logo, SmartArt, ikon, dan informasi kontak. Pelajari cara membuat tema sendiri dan menerapkannya secara konsisten.
  1. Tentukan Skema Warna Tema Profil Perusahaan
    • Tab Design → Variants → Colors → Customize Colors.
    • Masukkan kode warna sesuai skema warna korporat.
    • Simpan skema warna dengan nama Warna Profil Perusahaan
    Contoh ubah warna tema:
    Warna Hex
    Text/Background – Dark 1 #333333
    Text/Background – Light 1 #FFFFFF
    Text/Background – Dark 2 #005A9E
    Text/Background – Light 2 #F2F2F2
    Accent 1 #005A9E
    Accent 2 #F39C12
    Accent 3 #555555
    Accent 4 #6C757D
    Accent 5 #198754
    Accent 6 #DC3545
    Hyperlink #0D6EFD
    Followed Hyperlink #6F42C1
  2. Tentukan Skema Font Tema Profil Perusahaan
    • Tab Design → Variants → Fonts → Customize Fonts.
    • Pilih font untuk Heading dan Body sesuai skema font korporat.
      Contoh:
      • Heading font: Aptos
      • Body font: Aptos
    • Simpan skema font dengan nama Font Profil Perusahaan
  3. Slide 1 — Cover (Halaman Sampul)

    Pada latihan ini, Anda akan membuat halaman sampul (cover) untuk presentasi profil perusahaan.

    Langkah 1 — Tambahkan Slide Judul
    1. Buka presentasi PowerPoint.
    2. Pilih Home → New Slide → Title Slide (atau gunakan Slide pertama yang sudah tersedia).
    Langkah 2 — Isi Judul
    1. Klik Click to add text.
    2. Masukkan teks "PT MAJU JAYA INDONESIA". Pilih Font yang sudah dibuat sebelumnya Skema Font Tema Profil Perusahaan.
    Langkah 3 — Isi Subtitle
    1. Insert → Text Box.
    2. Masukkan Subtitle: "Profil Perusahaan 2026".
    3. Atur posisi subtitle di bawah judul.
    Langkah 4 — Sisipkan Logo Perusahaan
    1. Insert → Pictures → pilih logo perusahaan.
    2. Atur tata letak: Logo di kiri, Teks di kanan.
  4. Slide 2 — Visi & Misi:

    Pada latihan ini, Anda akan membuat Slide untuk menampilkan visi dan misi perusahaan.

    1. New Slide → Title Only.
    2. Judul: "VISI & MISI", font 36-40 pt, tebal.
    3. Visi (1 kalimat):
      • Insert → Text Box, ketik misal: "Menjadi perusahaan teknologi terpercaya di Indonesia."
      • Font 20-22 pt, tebal, rata tengah.
      • Beri Shape Fill ringan di belakang teks agar menonjol.
    4. Misi (3-5 poin):
      • Insert → Icons → cari ikon relevan (target, star, handshake).
      • Di samping tiap ikon, ketik misi dengan Text Box, font 18-20 pt.
      • Contoh: "Memberikan solusi inovatif bagi pelanggan."
    5. Gunakan Align untuk merapikan posisi ikon dan teks.
  5. Slide 3 — Struktur Organisasi (SmartArt):

    Pada latihan ini, Anda akan membuat Slide untuk menampilkan struktur organisasi perusahaan.

    1. New Slide → Title Only.
    2. Judul: "STRUKTUR ORGANISASI", font 36-40 pt.
    3. Insert → SmartArt → Hierarchy → Organization Chart.
    4. Isi teks di panel SmartArt:
      • Level 1: Direktur Utama
      • Level 2: Manager (Keuangan, Produksi, SDM)
      • Level 3: Staff di bawah tiap Manager
    5. Tab SmartArt Design → Change Colors → pilih warna tema korporat.
    6. Font dalam SmartArt menyesuaikan tema, minimal 12-14 pt agar terbaca.
  6. Slide 4 — Produk & Layanan:
    1. New Slide → Title Only.
    2. Judul: "PRODUK & LAYANAN", font 36-40 pt.
    3. Buat 3-4 kolom produk menggunakan Shapes:
      • Insert → Shapes → Rectangle: Rounded Corners.
      • Gambar 3-4 kotak berjajar, beri jarak sama.
      • Blok semua → Tab Shape Format → Align → Align Top + Distribute Horizontally.
    4. Isi tiap kotak:
      • Ikon: Insert → Icons (cari sesuai produk).
      • Nama produk: font 20-22 pt tebal, di bawah ikon.
      • Deskripsi singkat: font 16-18 pt, rata tengah.
    5. Warna kotak: Shape Fill → pilih warna tema korporat (Accent 1 atau 2).
  7. Slide 5 — Penutup:
    1. New Slide → Title Only.
    2. Judul: "TERIMA KASIH", font 44-48 pt, rata tengah.
    3. Di bawah judul, tambahkan Text Box berisi:
      • Tagline: "Mari Bekerja Sama!" font 20-22 pt, miring.
    4. Informasi Kontak (font 16-18 pt):
      • 📧 info@perusahaan.com
      • ☎ (021) 555-1234
      • 🌐 www.perusahaan.co.id
      Gunakan Insert → Icons untuk ikon email, telepon, website agar lebih profesional.
    5. Sosial Media:
      • Insert → Icons → cari Instagram, LinkedIn, YouTube.
      • Susun berjajar di bagian bawah slide.
    6. Rapikan dengan Align → Distribute Horizontally untuk ikon sosial media.
  8. Animasi (Opsional): Agar presentasi lebih profesional, tambahkan animasi Fade pada judul dan Wipe pada konten tiap slide. Atur Start → After Previous agar animasi berjalan otomatis.
  9. Hasil Akhir — Profil Perusahaan 5 Slide:

    Semua slide telah menggunakan tema kustom warna & font korporat dari langkah 1-2 di atas.

Latihan PPT 2024 — Sisipkan & Edit Gambar: Pelajari cara menyisipkan gambar, Remove Background, Crop to Shape Oval, serta mengatur posisi, ukuran, dan efek gambar.
  1. Buka PowerPoint → Blank Presentation.
  2. Pilih Layout: Tab Home → Layout → pilih Blank (agar gambar leluasa diatur tanpa batasan placeholder).
  3. Sisipkan gambar:
    • Tab Insert → Pictures → This Device → pilih file gambar.
      Contoh Gambar
  4. Klik 2x pada gambar → Tab Picture Format → Remove Background. PowerPoint akan mendeteksi latar belakang secara otomatis (warna ungu = area yang akan dihapus).
    Menjadi:
  5. Jika ada area yang salah deteksi: gunakan Mark Areas to Keep atau Mark Areas to Remove.
    1. Mark Areas to Keep
      Menandai bagian gambar yang tetap dipertahankan.
      PowerPoint terkadang salah mendeteksi objek sehingga ada bagian yang ikut dihapus, misalnya:
      • Rambut
      • Tangan
      • Kaki
      • Daun
      • Tas
      • Logo
      • Teks pada gambar
      Cara menggunakan :
      1. Klik Mark Areas to Keep.
      2. Kursor berubah menjadi ikon pensil dengan tanda .
      3. Klik atau gambar garis pendek pada area yang hilang.
      4. PowerPoint akan menganalisis area tersebut dan mengembalikannya ke objek.

      Tips: Tidak perlu mencoret seluruh objek. Biasanya cukup satu klik atau satu garis pendek pada area yang salah terhapus.

    2. Mark Areas to Remove
      Menandai bagian gambar yang harus dihapus. Digunakan jika masih ada background yang belum terhapus, misalnya:
      • Pohon
      • Tembok
      • Langit
      • Orang lain
      • Bayangan
      • Kabel
      • Kursi
      Cara menggunakan:
      1. Klik Mark Areas to Remove.
      2. Kursor berubah menjadi ikon pensil dengan tanda .
      3. Klik atau gambar garis pendek pada area background.
      4. Area tersebut akan dimasukkan ke bagian yang dihapus.
      Tips: Semakin pendek garis yang dibuat, biasanya hasil analisis PowerPoint semakin akurat.
      Hasil:
    3. Discard All Changes
      Membatalkan seluruh proses Background Removal.
      Jika diklik:
      • Semua tanda Keep dan Remove dihapus.
      • Gambar kembali seperti kondisi awal.
      • Tidak ada background yang dihapus.
      Gunakan jika ingin mengulang proses dari awal.
    4. Keep Changes
      Menyimpan hasil penghapusan background.
      Setelah diklik:
      • Area yang ditandai untuk dihapus menjadi transparan.
      • Mode Background Removal ditutup.
      • Anda kembali ke tab Picture Format.
      Jika hasilnya masih kurang baik, Anda dapat memilih gambar tersebut lagi dan menjalankan Remove Background kembali untuk melakukan penyesuaian.
  6. Tips: Zoom in (Ctrl + scroll) untuk marking yang lebih presisi.
  7. Klik Keep Changes → latar belakang gambar hilang.
  8. Crop gambar menjadi bentuk circle:
    • Klik gambar → Tab Picture Format → Crop → Crop to Shape.
    • Pilih Oval (dalam kategori Basic Shapes).
    • Klik kembali Crop → pilih Aspect Ratio → 1:1 (Square).
    • Sesuaikan posisi crop dengan drag handle.
    • Tekan Enter atau klik di luar gambar untuk selesai.
    Hasil:
  9. Atur posisi dan ukuran:
    • Klik gambar → drag sudut untuk mengubah ukuran (tahan Ctrl agar proporsional).
    • Drag gambar untuk memindahkan posisi.
  10. Tambahkan efek gambar (opsional):
    • Tab Picture Format → Picture Border → beri border putih (Optional). Atau
    • Tab Picture Format → Picture Effects → Shadow → pilih efek bayangan. Misalnya Perspective
  11. Tambahkan tema (opsional): Tab Design → pilih tema bawaan (misal: Ion) agar slide tidak polos.
  12. Simpan file: File → Save → beri nama misalnya Edit_Gambar.pptx.

Latihan PPT 2024 — Presentasi Interaktif 5 Slide: Buat presentasi interaktif dengan Hyperlink antar slide, Action Button navigasi, dan Video YouTube. Pelajari cara menghubungkan slide agar presentasi terasa seperti aplikasi.
Struktur Slide:
  • Slide 1: Menu Utama — Layout: Title Only
  • Slide 2: Bab 1 — Pendahuluan — Layout: Title Only
  • Slide 3: Bab 2 — Materi — Layout: Title Only
  • Slide 4: Bab 3 — Kesimpulan — Layout: Title Only
  • Slide 5: Video — Layout: Title Only
  1. Buka PowerPoint → Blank Presentation.
  2. Slide 1 — Menu Utama:
    • Judul: "Menu Presentasi", font 36-40 pt.
    • Buat 4 teks dengan Text Box (font 24-28 pt):
      "Bab 1", "Bab 2", "Bab 3", "Video".
    • Blok teks "Bab 1" → Klik kanan → Hyperlink (atau Ctrl+K).
    • Pilih Place in This Document → pilih Slide 2 (Bab 1) → OK.
    • Ulangi untuk "Bab 2 → Slide 3", "Bab 3 → Slide 4", "Video → Slide 5".
  3. Tambahkan Action Button "Kembali" di setiap Slide:
    • Buka Slide 2 (Bab 1).
    • Tab Insert → Shapes → Action Buttons → pilih Action Button: Home (ikon rumah).
    • Gambar di pojok kanan bawah.
    • Di dialog yang muncul: pilih Hyperlink → Place in This Document atau Slide… → pilih Slide 1.
    • Klik OK.
    • Copy-paste action button ke Slide 3, Slide 4, dan Slide 5.
  4. Font: Judul tiap slide 36-40 pt, isi konten 18-20 pt.
  5. Tambahkan video dari YouTube:
    • Buka Slide 5 → judul: "Video".
    • Tab Insert → Video → Online Video.
    • Paste URL YouTube (atau cari "Embed Code" dari YouTube).
    • Klik Insert → video akan muncul di Slide.
    • Alternatif: Jika Online Video gagal, gunakan Insert → Video → This Device dengan file contoh video .mp4 yang sudah di-download.
    • Atur ukuran dan posisi video.
    • Set video play otomatis: Tab Playback → Start → Automatically.
  6. Uji coba: Tekan F5 (Slide Show) → klik "Bab 1" → navigasi → klik Action Button kembali → coba video.
  7. Tambahkan tema (opsional): Tab Design → pilih tema bawaan agar tampilan lebih konsisten antar slide.
  8. Simpan file: File → Save → beri nama misalnya Presentasi_Interaktif.pptx.

Latihan PPT 2024 — Animasi Proses Bisnis: Buat animasi proses bisnis dengan Fade Entrance berurutan, Grow/Shrink Emphasis, dan Motion Path. Pelajari cara mengatur Timing dan Animation Pane.
  1. Buka PowerPoint → Blank Presentation.
  2. Buat Slide baru: Tab Home → New Slide → pilih layout Title Only → judul: "Proses Bisnis Animasi", font 36-40 pt.
  3. Buat objek di Slide:
    • Buat 4 kotak (Insert → Shapes → Rounded Rectangle) secara horizontal berjauhan.
    • Isi teks: PROSPEK, PENAWARAN, NEGOSIASI, DEAL, font 20-24 pt tebal.
    • Buat 3 panah (Insert → Shapes → Arrow: Right Arrow) di antara kotak.
  4. Tambahkan Animasi Entrance (Fade):
    • Klik kotak "PROSPEK" → Tab Animations → pilih Fade.
    • Klik Panah setelah "PROSPEK" → pilih Fade.
    • Klik kotak "PENAWARAN" → pilih Fade.
    • Klik Panah setelah "PENAWARAN" → pilih Fade.
    • Klik kotak "NEGOSIASI" → pilih Fade.
    • Klik Panah setelah "NEGOSIASI" → pilih Fade.
    • Klik kotak "DEAL" → pilih Fade.
  5. Atur Timing Animasi:
    • Tab Animations → Animation Pane.
    • Klik panah bawah pada masing-masing animasi di panel → atur:
      • "PROSPEK" → Start: On Click (muncul saat klik).
      • "Panah 1 " → Start: After Previous (otomatis setelah Prospek).
      • "PENAWARAN" → Start: After Previous
      • "Panah 2 " → Start: After Previous.
      • "NEGOSIASI" → Start: After Previous.
      • "Panah 3 " → Start: After Previous.
      • "DEAL" → Start: After Previous.
  6. Tambahkan Emphasis (Grow) pada "DEAL":
    • Klik kotak "DEAL" → Tab Animations → Add Animation.
    • Pilih Grow/Shrink (dalam group Emphasis).
      Atur Start: With Previous.
    • Kemudian klik Effect Options
      Beri centang pada Auto-reverse untuk efek grow-shrink kembali ke ukuran semula.
    • Tab Timing Duration: 1s.
  7. Tambahkan Motion Path pada "PROSPEK", ini Opsional
    Geser posisi "PROSPEK" menjadi seperti contoh gambar
    • Klik kotak "PROSPEK" → Tab Animations → Motion Paths → Lines.
    • Klik garis motion path → tarik ujung garis ke arah kanan (atau geser sesuai keinginan).
      Menjadi sepertri ini:
    • Tab Timing Start: With Previous, Duration: 1s.
  8. Uji coba: Tekan F5 → klik sekali → animasi berjalan otomatis berurutan.
  9. Tambahkan tema (opsional): Tab Design → pilih tema bawaan untuk mempercantik slide.
  10. Simpan file: File → Save → beri nama misalnya Animasi_Proses_Bisnis.pptx.

Latihan PPT 2024 — Transisi 4 Slide: Buat 4 slide dengan transisi berbeda: Fade, Push, Wipe, dan Morph. Atur durasi 2 detik dan auto-advance After 3 detik.
  1. Buka PowerPoint → Blank Presentation.
  2. Pilih Layout: Tab Home → Layout → pilih Title Only.
  3. Buat 4 Slide: Klik kanan di Slides panel → New Slide (ulangi 3 kali).
  4. Isi tiap Slide dengan judul berbeda (font 36-40 pt):
    • Slide 1 → "Fade"
    • Slide 2 → "Push"
    • Slide 3 → "Wipe"
    • Slide 4 → "Morph"
  5. Terapkan Transisi:
    • Klik Slide 1 → Tab Transitions → pilih Fade.
    • Klik Slide 2 → pilih Push.
    • Klik Slide 3 → pilih Wipe.
    • Klik Slide 4 → pilih Morph.
  6. Atur Durasi Transisi:
    • Di tab Transitions, pada grup Timing:
    • Duration: ketik 2 (atau gunakan tombol spinner atas/bawah hingga muncul 02,00).
    • Ulangi untuk masing-masing Slide, atau klik
  7. Atur auto-advance:
    • Pada grup Timing, centang After → ketik 3 (PowerPoint otomatis mengonversi ke 00:03,00).
    • Penting: Di PowerPoint 2024, centang On Mouse Click dan After bisa aktif bersamaan. Slide akan maju otomatis setelah 3 detik, tetapi tetap bisa diklik manual kapan saja.
    • Ulangi untuk semua Slide.
    • Jalankan Slide show (F5) → Slide akan berganti otomatis setiap 3 detik.
  8. Catatan Morph: Transisi Morph di Slide 4 akan bekerja optimal jika Slide 3 dan Slide 4 memiliki objek dengan nama yang sama (misal: hasil duplikasi Slide). Lihat 👉 latihan Pertemuan 3 Menengah ini untuk teknik Morph lengkap.
  9. Simpan file: File → Save → beri nama misalnya 4_Slide_Transisi.pptx.

Latihan PPT 2024 — Morph Transition: Buat efek Morph sinematik dengan menduplikat slide dan mengubah posisi/ukuran objek. Pelajari syarat utama Morph: nama objek harus identik.
  1. Buka PowerPoint → Blank Presentation.
  2. Pilih Layout: Tab Home → Layout → pilih Blank (agar leluasa menempatkan teks dan gambar).
  3. Buat Slide 1:
    • Hapus semua placeholder default jika masih ada.
    • Insert → Text Box → ketik: "IDE".
    • Font: Arial Black, size 96 pt, warna biru tua.
    • Posisikan di pojok kiri Slide.
  4. Duplikat Slide 1 menjadi Slide 2:
    • Klik kanan Slide 1 di panel → Duplicate Slide.
  5. Edit Slide 2:
    • Pindahkan teks "IDE" ke pojok kanan atas.
    • Ubah ukuran font menjadi 36 pt.
    • Tambahkan Text Box baru dengan deskripsi: "Sebuah gagasan yang mengubah dunia".
    • Font deskripsi: 20 pt, warna abu-abu.
    • Tambahkan gambar ilustrasi (Insert → Pictures).
      Download Contoh Gambar
  6. Terapkan Morph transition pada Slide 2:
    • Klik Slide 2 → Tab Transitions → pilih Morph.
    • Durasi: set 2 (atau gunakan spinner hingga 02,00).
  7. Uji coba: Tekan F5 → klik ke Slide 2 → teks "IDE " akan bergerak mulus dari kiri ke kanan sambil mengecil, sementara deskripsi dan gambar muncul.
  8. Simpan file: File → Save → beri nama misalnya 3_Morph_Ide.pptx.
Mengapa Morph berhasil? Morph membaca objek yang memiliki nama sama di kedua Slide. Karena kita menduplikat Slide 1, teks "IDE" di Slide 2 memiliki nama objek yang identik. Jika membuat dari Slide baru (bukan duplikat), Morph tidak akan bekerja — pastikan selalu duplikat Slide untuk efek Morph objek yang sama.

  6. Slide 5 (Penutup): Layout Title Slide. Ucapan terima kasih dan kontak perusahaan.
  7. Tambah tema (opsional): Tab Design → pilih tema yang sesuai.
  8. Simpan file: File → Save As → T1_Profil_Perusahaan.pptx.

Tugas 2 — Animasi & Transisi: Buka file Tugas 1, tambahkan animasi Fade pada bullet poin, transisi Push antar slide, dan atur auto-advance 3 detik.
  1. Buka file T1_Profil_Perusahaan.pptx.
  2. Pilih bullet poin di Slide 2 → Tab Animations → pilih Fade.
  3. Atur Start: After Previous   Duration: 01.00.
  4. Gunakan Animation Painter untuk menyalin animasi ke bullet di Slide 3 dan 4.
  5. Klik Slide 1 → Tab Transitions → pilih Push → klik Apply To All.
  6. Pada grup Timing, centang After → ketik 3 → klik Apply To All.
  7. Uji coba: Tekan F5 — slide berganti otomatis tiap 3 detik dengan animasi.
  8. Simpan file: File → Save As → T2_Animasi_Transisi.pptx.

Tugas 3 — Navigasi Hyperlink: Buat presentasi 5 slide dengan Slide 1 sebagai menu. Gunakan Action Button untuk navigasi antar slide.
  1. Buka PowerPoint → Blank Presentation.
  2. Buat 5 Slide dengan layout Title Only.
  3. Slide 1 (Menu): Judul "Daftar Isi". Buat 4 teks (Slide 2–5) sebagai menu. Insert → Text Box untuk tiap item.
  4. Beri Hyperlink pada tiap teks menu: Klik kanan teks → Link → Place in This Document → pilih slide tujuan.
  5. Slide 2–5 (Konten): Isi judul dan konten masing-masing (misal: Visi, Produk, Galeri, Kontak).
  6. Pada tiap Slide 2–5, tambahkan Action Button: Insert → Shapes → Action Button: Home → gambar di slide → Hyperlink to: Slide 1.
  7. Ulangi untuk semua slide konten.
  8. Uji coba: Tekan F5 → klik menu → navigasi berfungsi.
  9. Simpan file: File → Save As → T3_Navigasi.pptx.

Tugas 4 — Visualisasi Data: Buat presentasi 3 slide: Cover, tabel + SmartArt kategorisasi, dan grafik penjualan. Gunakan tema korporat.
  1. Buka PowerPoint → Blank Presentation.
  2. Slide 1 (Cover): Layout Title Slide. Judul "Laporan Penjualan" + nama perusahaan.
  3. Slide 2 (Data Kategorisasi): Layout Title Only. Judul "Kategori Produk".
    • Insert → Table → 4 baris × 3 kolom. Isi: No, Kategori, Jumlah.
    • Di bawah tabel: Insert → SmartArt → List → pilih gaya sesuai data.
  4. Slide 3 (Grafik Penjualan): Layout Title Only. Judul "Grafik Penjualan".
    • Insert → Chart → Column → isi data di sheet Excel yang muncul.
    • Sesuaikan judul sumbu dan legenda.
  5. Tambah tema: Tab Design → pilih tema korporat (biru/abu).
  6. Simpan file: File → Save As → T4_Visualisasi_Data.pptx.

Tugas 5 — Final Project: Gabungkan semua keterampilan: buat template kustom via Slide Master, 5 slide dengan animasi, transisi Morph, dan navigasi action button.
  1. Buka PowerPoint → Blank Presentation.
  2. Buat template via Slide Master:
    • Tab View → Slide Master.
    • Pada Slide paling atas: Insert → logo perusahaan di kanan atas.
    • Tab Slide Master → Colors → Customize Colors → buat tema warna (Accent 1: biru #005A9E, Accent 2: abu #F2F2F2).
    • Tab Slide Master → Fonts → atur Heading: Calibri Light, Body: Calibri.
    • Close Master View.
  3. Buat 5 Slide:
    • Slide 1 (Cover): Layout Title Slide. Judul produk + subjudul.
    • Slide 2 (Produk 1): Layout Title Only. Gambar + deskripsi.
    • Slide 3 (Produk 2): Duplikat Slide 2 → ganti gambar & teks.
    • Slide 4 (Produk 3): Layout Title Only. Ikon + bullet poin.
    • Slide 5 (Penutup): Layout Title Slide. Kontak + ajakan (CTA). Insert → Icons → pilih ikon sosial media.
  4. Animasi: Pilih elemen tiap slide → Tab Animations → Fade → After Previous, durasi 01.00.
  5. Transisi Morph: Klik Slide 3 → Tab Transitions → Morph (karena Slide 3 hasil duplikat Slide 2).
  6. Navigasi: Di Slide 2–4, tambahkan Insert → Shapes → Action Button: Home → Hyperlink to: Slide 1 sebagai tombol Back.
  7. Uji coba: Tekan F5 — pastikan animasi, Morph, dan navigasi berjalan.
  8. Simpan file kerja: File → Save As → PowerPoint Presentation (*.pptx) → T5_Final_Project.pptx.
  9. Simpan sebagai template (opsional): File → Save As → PowerPoint Template (*.potx) → T5_Template_Korporat.potx.
