Materi Lengkap

Langkah Praktik:

  1. Buka PowerPoint → pilih Blank Presentation.
  2. Pilih tema: Tab Design → pilih salah satu tema (misal: Ion, Retrospect, atau Frame).
  3. Slide 1 — Cover:
    • "Click to add title" ketik: "PRESENTASI DIRI" (font besar 44 pt).
    • Klik Insert → Pictures → This Device.
    • Atur foto: Klik 2x pada Foto → Picture Format → Crop → Crop to Shape → pilih Oval.
  4. Slide 2 — Pendidikan & Pengalaman:
    • Klik tab Home.
    • Klik New Slide.
    • Pilih layout Two Content.
    Akan muncul Slide baru dengan dua kotak:
    • Kotak judul di atas.
    • Kotak isi di tengah.
  5. Slide 3 — Hobi & Minat:
    • Klik Home → New Slide.
    • Pilih layout Title Only → judul: "Hobi & Minat".
    • Tambahkan Ikon:
      • Klik Insert → Icons.
        Pada kotak pencarian, cari:
        • Music
        • Sport
        • Book
        Pilih beberapa ikon dan Klik Insert.
      Atur posisi ikon berjajar secara horizontal dengan cara
      Pilih atau seleksi ketiga icon.
      Pada Tab Graphics Format → Klik Align → pilih Align Middle dan Distribute Horizontally.
    • Untuk mengubah warna ikon: Pilih ikon → Tab Graphics Format → Graphics Fill → pilih warna.
    • Gunakan Text Box di bawah masing-masing ikon.
      • Musik
        Mendengarkan musik untuk hiburan dan relaksasi.
      • Olahraga
        Bermain badminton untuk menjaga kesehatan.
      • Membaca
        Membaca buku teknologi dan pengembangan diri.

      👉 Gunakan Align untuk menata posisi teks agar sejajar dengan ikon.

      Pilih semua Text Box (3 Text Box) → Tab Shape Format → Klik Align → pilih Align Middle dan Distribute Horizontally.
      Jangan lupa untuk teks Rata Tengah semua.
  6. Simpan file: File → Save → beri nama misalnya Presentasi_Diri.pptx.

Bagian 1 — Struktur Organisasi
  1. Buka PowerPoint → pilih Blank Presentation.
  2. Layout → Title Only → judul: STRUKTUR ORGANISASI.
  3. Tab Insert → SmartArt → pilih Hierarchy → pilih Organization Chart.
  4. Klik kotak paling atas → ketik: Direktur.
  5. Klik kotak level 2 → ketik: Manager.
  6. Klik kotak level 3 → ketik: Staff untuk masing-masing manager.
  7. Jika ingin menambah kotak: Klik kanan pada Kotak → Add Shape → pilih Add Assistant.
  8. Jika ingin ubah warna: Tab SmartArt Design → Change Colors → pilih skema warna.
  9. Jika ingin ubah Tema: Tab SmartArt Styles → pilih tema warna.
Bagian 2 — Diagram Proses Bisnis
  1. Buat Slide baru: klik panah kecil New Slide → Title Only → judul: PROSES BISNIS.
  2. Tab Insert → Shapes → pilih Rectangle: Rounded Corners.
  3. Gambar 4 kotak secara horizontal beri jarak (buka Latihan Dasar sebelumnya).
  4. Klik kanan masing-masing kotak → Edit Text → ketik: PROSPEK, PENAWARAN, NEGOSIASI, DEAL.
  5. Insert → Shapes → pilih Arrow (Right) → gambar panah dari kotak 1 ke 2, 2 ke 3, 3 ke 4.
  6. Blok semua shapes + panah → Tab Shape Format → Align → Align Middle, lalu Distribute Horizontally agar jarak antar kotak sama rata.
  7. Ubah warna shapes: Shape Fill → Gradient pilih warna biru gradasi.
Bagian 3 — SmartArt Cycle
  1. Buat Slide baru: klik panah kecil New Slide → Title Only → judul: SIKLUS PENJUALAN.
  2. Insert → SmartArt → pilih Cycle → Basic Cycle.
  3. Ketik teks di masing-masing lingkaran: Prospek, Penawaran, Negosiasi, Deal.
  4. Jika ingin ubah warna dan gaya, klik SmartArt di halaman Slide kemudian dari Tab SmartArt Design.

Langkah Praktik:

  1. Buka PowerPoint → Blank Presentation.
  2. Sisipkan gambar:
    • Tab Insert → Pictures → This Device → pilih file gambar.
      Contoh Gambar
  3. Klik 2x pada gambar → Tab Picture Format → Remove Background. PowerPoint akan mendeteksi latar belakang secara otomatis (warna ungu = area yang akan dihapus).
    Menjadi:
  4. Jika ada area yang salah deteksi: gunakan Mark Areas to Keep atau Mark Areas to Remove.
    1. Mark Areas to Keep
      Menandai bagian gambar yang tetap dipertahankan.
      PowerPoint terkadang salah mendeteksi objek sehingga ada bagian yang ikut dihapus, misalnya:
      • Rambut
      • Tangan
      • Kaki
      • Daun
      • Tas
      • Logo
      • Teks pada gambar
      Cara menggunakan :
      1. Klik Mark Areas to Keep.
      2. Kursor berubah menjadi ikon pensil dengan tanda .
      3. Klik atau gambar garis pendek pada area yang hilang.
      4. PowerPoint akan menganalisis area tersebut dan mengembalikannya ke objek.

      Tips: Tidak perlu mencoret seluruh objek. Biasanya cukup satu klik atau satu garis pendek pada area yang salah terhapus.

    2. Mark Areas to Remove
      Menandai bagian gambar yang harus dihapus. Digunakan jika masih ada background yang belum terhapus, misalnya:
      • Pohon
      • Tembok
      • Langit
      • Orang lain
      • Bayangan
      • Kabel
      • Kursi
      Cara menggunakan:
      1. Klik Mark Areas to Remove.
      2. Kursor berubah menjadi ikon pensil dengan tanda .
      3. Klik atau gambar garis pendek pada area background.
      4. Area tersebut akan dimasukkan ke bagian yang dihapus.
      Tips: Semakin pendek garis yang dibuat, biasanya hasil analisis PowerPoint semakin akurat.
      Hasil:
    3. Discard All Changes
      Membatalkan seluruh proses Background Removal.
      Jika diklik:
      • Semua tanda Keep dan Remove dihapus.
      • Gambar kembali seperti kondisi awal.
      • Tidak ada background yang dihapus.
      Gunakan jika ingin mengulang proses dari awal.
    4. Keep Changes
      Menyimpan hasil penghapusan background.
      Setelah diklik:
      • Area yang ditandai untuk dihapus menjadi transparan.
      • Mode Background Removal ditutup.
      • Anda kembali ke tab Picture Format.
      Jika hasilnya masih kurang baik, Anda dapat memilih gambar tersebut lagi dan menjalankan Remove Background kembali untuk melakukan penyesuaian.
  5. Tips: Zoom in (Ctrl + scroll) untuk marking yang lebih presisi.
  6. Klik Keep Changes → latar belakang gambar hilang.
  7. Crop gambar menjadi bentuk circle:
    • Klik gambar → Tab Picture Format → Crop → Crop to Shape.
    • Pilih Oval (dalam kategori Basic Shapes).
    • Klik kembali Crop → pilih Aspect Ratio → 1:1 (Square).
    • Sesuaikan posisi crop dengan drag handle.
    • Tekan Enter atau klik di luar gambar untuk selesai.
    Hasil:
  8. Atur posisi dan ukuran:
    • Klik gambar → drag sudut untuk mengubah ukuran (tahan Ctrl agar proporsional).
    • Drag gambar untuk memindahkan posisi.
  9. Tambahkan efek gambar (opsional):
    • Tab Picture Format → Picture Border → beri border putih (Optional). Atau
    • Tab Picture Format → Picture Effects → Shadow → pilih efek bayangan. Misalnya Perspective

Langkah Praktik:
Panduan visual: Pertemuan 3 belum dilengkapi tangkapan layar. Gunakan petunjuk teks di bawah dan contoh file yang bisa diunduh sebagai referensi. Jika ragu dengan posisi tombol, lihat kembali tangkapan layar dari Pertemuan 1–2 yang menunjukkan tata letak ribbon PowerPoint.

  1. Buka PowerPoint → Blank Presentation.
  2. Buat 4 Slide: Klik kanan di Slides panel → New Slide (ulangi 3 kali).
  3. Isi tiap Slide dengan judul berbeda: "Slide 1 — Fade", "Slide 2 — Push", "Slide 3 — Wipe", "Slide 4 — Morph".
  4. Terapkan transisi:
    • Klik Slide 1 → Tab Transitions → pilih Fade.
    • Klik Slide 2 → pilih Push.
    • Klik Slide 3 → pilih Wipe.
    • Klik Slide 4 → pilih Morph.
  5. Atur durasi transisi:
    • Di tab Transitions, pada grup Timing:
    • Duration: ketik 2 (atau gunakan tombol spinner atas/bawah hingga muncul 02.00).
    • Ulangi untuk masing-masing Slide.
  6. Atur auto-advance:
    • Pada grup Timing, centang After → ketik 3 (PowerPoint otomatis mengonversi ke 00:03.00).
    • Penting: Di PowerPoint 2024, centang On Mouse Click dan After bisa aktif bersamaan. Slide akan maju otomatis setelah 3 detik, tetapi tetap bisa diklik manual kapan saja.
    • Ulangi untuk semua Slide.
    • Jalankan Slide show (F5) → Slide akan berganti otomatis setiap 3 detik.

Jika membuat dari Slide baru (bukan duplikat), Morph tidak akan bekerja — pastikan selalu duplikat Slide untuk efek Morph objek yang sama.

      • Slide 1:

Bagian 1 — Membuat Slide Master
  1. Buka Slide Master
    Tab View → Slide Master
    pilih Slide paling atas.
  2. Tambahkan Logo
    letakkan di pojok kiri atas agar muncul di seluruh Slide.
    Ukuran sekitar 3 cm × 3 cm.
    Contoh Logo
  3. Ubah Warna Tema Warna Korporat:
    Pilih Customize Colors...
    Untuk latihan, yang penting adalah:
    • Accent 1 = Biru
    • Accent 2 = Orange
    • Accent 3 = Abu-abu

    Memasukkan kode HEX → More Colors...

    Theme Color Warna HEX Fungsi
    Accent 1 🔵 Biru #0B5ED7 Warna utama (Primary)
    Accent 2 🟠 Orange #F39C12 Warna aksen
    Accent 3 ⚫ Abu-abu #555555 Warna sekunder
    Background / Light 1 ⚪ Putih #FFFFFF Latar belakang

    Beri nama warna tema, misalnya "Tema Biru Korporat"
    Klik Save.

  4. Font Korporat:
    Pilih Customize Fonts...
    • Heading: Calibrit
    • Body: Aptos

    Beri nama tema font, misalnya "Font Korporat"
    Klik Save.

  5. Buat layout baru
    Pilih Slide Master paling atas → Insert Layout
    Akan muncul layout baru di Slide yang paling bawah dengan nama Custom Layout (atau Layout baru).
    Rename layout tersebut:
    Klik kanan pada layout → Rename Layout
    Ubah menjadi: Judul + Gambar Kiri
    Tambahkan placeholder untuk gambar di sebelah kiri:
    • Tab Slide Master → Insert Placeholder → Picture
    • Gambar placeholder akan muncul di layout, ubah ukurannya menjadi setengah Slide (kiri)
    • Tambahkan placeholder untuk teks di sebelah kanan:
      Tab Slide Master → Insert Placeholder → Text
    • Ubah ukuran placeholder teks menjadi setengah Slide (kanan)
    Hasil:
  6. Close Master View. Sekarang seluruh Slide memakai desain yang sama dan kembali ke tampilan normal.
    placeholder Footer di Slide Master tidak otomatis muncul pada Slide. PowerPoint memperlakukan Footer berbeda dengan placeholder biasa.
    Mengapa Footer tidak muncul?
    Meskipun di Slide Master Anda sudah mengaktifkan:
    • ✓ Date
    • ✓ Footer
    • ✓ Slide Number
    placeholder tersebut baru akan diisi jika Footer diaktifkan melalui menu Insert.
    Keluar dari Slide Master (Close Master View), lalu lakukan langkah berikut:
    • Buka tab Insert.
    • Klik Header & Footer.
    • Pada tab Slide:
      • ✓ Centang Date and time (opsional)
      • ✓ Centang Slide number (opsional)
      • ✓ Centang Footer
      • ✓ Isi teks footer, misalnya: PT Maju Jaya
      • ✓ Klik Apply to All.
    Sekarang footer akan muncul pada semua Slide yang menggunakan layout tersebut.
